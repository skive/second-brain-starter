# BOOTSTRAP — инструкция агенту

> Этот файл написан не для человека, а для ИИ-агента, которому дали ссылку на
> репозиторий и сказали развернуть базу знаний. Выполняй шаги по порядку.

## Что нужно сделать

Развернуть у пользователя рабочую базу знаний из папки `vault/` этого репозитория
и сразу провести онбординг, чтобы правила были заполнены его ответами, а не
плейсхолдерами.

## Шаг 0. Спросить одно

Задай ровно один вопрос: **в какой папке разворачивать базу**. Предложи разумное
значение по умолчанию для его системы (например `~/Documents/KB` или
`C:\Users\<имя>\Documents\KB`). Остальное не спрашивай — всё, что нужно узнать
о человеке, спросит скилл онбординга на шаге 4.

Если папка существует и не пуста — остановись и спроси, что делать. Ничего не
затирай молча.

## Шаг 1. Получить содержимое

Клонируй репозиторий во временную папку:

```
git clone --depth 1 https://github.com/skive/second-brain-starter <временная папка>
```

Если git недоступен, скачай архив репозитория и распакуй.

## Шаг 2. Разложить базу

Скопируй **содержимое** `vault/` (включая скрытую папку `.claude`) в целевую папку.
Сам репозиторий, `README.md`, `BOOTSTRAP.md` и `scripts/` пользователю не нужны —
не копируй их. Временную папку удали.

В целевой папке должно оказаться:

```
CLAUDE.md            правила базы, пока с плейсхолдерами
index.md             пустое оглавление
00_Система/          лента, открытые вопросы, журнал решений, журнал сессий
Inbox/               входящее
Archive/             архив разобранного
90-Шаблоны/          формы заметок
95-Ритуалы/          приём входящего и еженедельный проход
.claude/skills/      скилл онбординга
```

Файлы `.gitkeep` в пустых папках удали — они нужны только репозиторию.

## Шаг 3. Включить историю

Выполни `git init` в целевой папке и сделай первый коммит с сообщением
«База развёрнута из second-brain-starter». Если пользователь не хочет git —
пропусти шаг, но скажи, что откат изменений агента станет невозможен.

Скрипты `scripts/bootstrap.sh` и `scripts/bootstrap.ps1` делают шаги 1–3 одной
командой. Пользуйся ими, если умеешь запускать команды в системе пользователя;
если нет — выполняй шаги файловыми операциями.

## Шаг 4. Провести онбординг

Прочитай `.claude/skills/second-brain-onboarding/SKILL.md` в целевой папке
и выполни описанный там сценарий целиком. Это обязательная часть разворачивания,
а не предложение на будущее: база с незаполненными плейсхолдерами бесполезна.

## Шаг 5. Отчитаться

Скажи коротко: где развёрнута база, что создано, что осталось незаполненным
и когда первый еженедельный проход.

## Чего не делать

- Не менять содержимое `CLAUDE.md` за пределами разделов 1, 2 и 6.
- Не заводить папки и темы, о которых пользователь не говорил.
- Не тащить в базу файлы пользователя без его слова — сначала спроси.
- Не сообщать об успехе того, чего не проверил.
